# Contributing

Thank you for your interest in contributing to AI Interview Coach!

To contribute to the project, please follow these steps:

1. Fork the repository.
2. Create a new feature or fix branch.
3. Make your changes.
4. Commit your changes with a clear and descriptive commit message.
5. Push your branch to your fork.
6. Open a Pull Request (PR).
7. Wait for the maintainer's review and address any requested feedback.

We appreciate contributions of all kinds, including bug fixes, documentation improvements, new features, and performance enhancements.
